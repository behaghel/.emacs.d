* Org Comments

=org-comments= provides Org-native review comments with clean source buffers,
local Org sidecars, and a backend protocol for remote comment systems.

Local comments are stored next to the source document in =.comments.org= files.
Remote integrations such as Confluence can register backends for opening,
pushing, pulling, and syncing comments without coupling the generic package to a
specific provider.

The full user manual is in =docs/org-comments.org= and can be built as an Emacs
Info manual.

* Highlights

- Source Org buffers stay clean.
- Local sidecars are ordinary Org files.
- =org-comments-mode= provides Org-native commands and overlays.
- Backends provide remote comment operations through a generic protocol.
- Collaboration state is backend-neutral: remote state, local state, sync state,
  resolved/actionable flags, and people identity use provider-independent
  fields.
- Legacy =HUB_COMMENT_*= metadata is migrated explicitly to =ORG_COMMENTS_*=.

* Installation from a checkout

The package requires Emacs 29.1+, Org 9.6+, and =context-panels= 0.1.0+,
including its =context-panels-org.el= library.  Obtain =context-panels= from
[[https://github.com/behaghel/context-panels][behaghel/context-panels]] or use an existing compatible installation.  No
Copilot, publishing adapter, private configuration, or credentials are needed
for local comments.  If using Emacs's built-in Org, ensure it meets the declared
minimum version; otherwise install a compatible Org separately.

For source directories on disk:

#+begin_src emacs-lisp
(add-to-list 'load-path "/path/to/context-panels")
(add-to-list 'load-path "/path/to/org-comments")
(require 'org-comments)
(add-hook 'org-mode-hook #'org-comments-mode)
#+end_src

* First use

=org-comments-mode= is the main user entry point.  Enable it per buffer with
=M-x org-comments-mode= or automatically from =org-mode-hook=.

1. Open an Org file.
2. Enable =org-comments-mode=.
3. Select a region and run =M-x org-comments-create=.
4. Open the panel with =M-x org-comments-open=.
5. Navigate with =org-comments-next= and =org-comments-previous=.

By default the mode shows inline and page-comment overlays.  Set
=org-comments-enable-overlays= to nil for a commands-only setup.

* Standalone verification in this repository

From the configuration repository root, run:

#+begin_src shell
CONTEXT_PANELS_PATH=/path/to/context-panels \
  devenv -q shell -- ./scripts/org-comments-standalone
#+end_src

When =CONTEXT_PANELS_PATH= is unset, the check uses
=STRAIGHT_BUILD_PATH/context-panels=, defaulting to this checkout's
=straight/build/context-panels=.  A missing dependency fails visibly; the check
does not download packages or load =init.el=.

The check copies package source, its tests, and the two context-panels libraries
into a temporary directory.  It uses a temporary home, plain =emacs -Q=, and no
sibling packages, configuration libraries, or shared repository test helpers.
It runs the full package ERT suite, including create/reopen/panel navigation,
then byte-compiles the package with warnings treated as errors.  Emacs network
connections are disabled during the check.  Temporary files are removed on exit.

For a hands-on acceptance session, append =--interactive=:

#+begin_src shell
CONTEXT_PANELS_PATH=/path/to/context-panels \
  devenv -q shell -- ./scripts/org-comments-standalone --interactive
#+end_src

1. Select =selected text= in the sample document.
2. Run =M-x org-comments-create=, write a comment in the sidecar, and save it.
3. Confirm the source document still contains only its original text.
4. Kill both file buffers, reopen =draft.org=, and enable =org-comments-mode=.
5. Run =M-x org-comments-open= and press =RET= on the comment row.  Point returns
   to the original selected text.

This session uses disposable files, not your own documents.  Exit Emacs when
finished; the sample source and sidecar are then deleted.

* Backend identity resolution

Backends can resolve remote account IDs for headings and UI display by setting
=org-comments-resolve-account-id-function=.  The callback receives an account ID
and optional directory context, and returns a display name or nil.
