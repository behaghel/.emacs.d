#+title: Standalone marginalia

This document uses native named Org footnotes only.  No comment sidecars,
accounts, publishing adapters, or AI packages are involved.

Open the side panel with M-x context-panels-open.  In the panel, press RET on
each note row: point should return to its reference in the prose below, not to
its definition.  Disabling cp-org-marginalia-context-panel-mode does not alter this
source document.
